# Student Tech Hub

A beginner-friendly full-stack web application that allows students to view upcoming technical events and register for the Tech Hub.

## Project Structure

This project is separated into a frontend and a backend:
- **`frontend/`**: Contains HTML, CSS, and JavaScript files for the user interface. It runs in the web browser.
- **`backend/`**: Contains a Python FastAPI server that handles data requests and logic.

## How the Frontend Communicates with the Backend

The frontend uses JavaScript's `fetch()` API to make HTTP requests over the network to the backend server:
1. When you click "Load Events", the frontend sends a `GET` request to `http://localhost:8000/api/events`. The backend replies with JSON data containing the events, and the frontend updates the page to display them.
2. When you fill out the registration form and submit it, the frontend sends a `POST` request to `http://localhost:8000/api/register` with your name and email. The backend receives this data and sends back a success message.

Because the frontend and backend are running on different ports locally (e.g., frontend opening directly from a file or local server, and backend on port 8000), the backend has **CORS (Cross-Origin Resource Sharing)** enabled in `main.py`. This tells the browser that it is safe to allow the frontend to request data from the backend.

## 🚀 Getting Started

### 1. Backend Setup

You need Python installed on your computer.

1. Open your terminal or command prompt.
2. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
3. (Optional but recommended) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On Mac/Linux:
   source venv/bin/activate
   ```
4. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the backend server using Uvicorn:
   ```bash
   uvicorn main:app --reload
   ```
   The backend is now running at `http://localhost:8000`. You can also visit `http://localhost:8000/docs` in your browser to see interactive API documentation automatically generated by FastAPI.

### 2. Frontend Setup

1. Open the `frontend` folder in your file explorer.
2. Simply double-click the `index.html` file to open it in your web browser. 
3. (Alternative) If you use VS Code, you can use the "Live Server" extension to serve the HTML file.

With the backend server running, you should be able to click the "Load Events" button and see events appear, as well as register successfully using the form!
